# RAE-HMC

Research code for RAE-HMC, a retrieval-augmented encoder framework for
hierarchical multi-label text classification.

The project contains the main RAE-HMC training pipeline, Web of Science
multi-seed experiments, ablation studies, baseline runners, and analysis
utilities for paired statistical tests.

## Overview

RAE-HMC combines:

- a shared Transformer encoder for input texts and label descriptions,
- retrieval-augmented semantic memory over hierarchical labels,
- a dual-branch hierarchical classifier with global and local branches,
- contrastive learning variants for sample-level and hard-negative mining,
- validation-time tuning for retrieval and prediction thresholds.

The main evaluation metrics are micro-F1 and macro-F1.

## Project Structure

```text
.
├── train_rae_hmc.py              # Main RAE-HMC training, validation, and test pipeline
├── encoder.py                    # Shared Transformer encoder
├── memory.py                     # FAISS-based semantic memory retrieval
├── classifier.py                 # Hierarchical classifier and losses
├── inference.py                  # Prediction and hierarchy-aware inference
├── build_hierarchy_utils.py      # Hierarchy parsing and multi-hot label utilities
├── run_wos_multiseed.py          # WOS46985 single-seed and multi-seed experiments
├── run_ablation_multiseed.py     # Module ablation experiments
├── run_ablation_cl_multiseed.py  # Contrastive-loss ablation experiments
├── run_baselines_multiseed.py    # Baseline comparison runner
├── run_sensitivity_memory.py     # Memory hyperparameter sensitivity experiments
├── analyze_paired_test.py        # Mean/std tables and paired t-tests
├── similarity_heatmap.py         # Similarity heatmap visualization
├── plot_sensitivity_memory.py    # Sensitivity curve plotting
├── dataset/                      # Local and WOS datasets plus preprocessing utilities
└── baselines/                    # Baseline implementations used for comparison
```

Generated experiment outputs, logs, model checkpoints, and temporary files are
ignored by Git. They should be regenerated locally when needed.

## Data

The default local dataset path is:

```text
dataset/dataset.csv
```

It should contain:

```text
text,labels
```

where `labels` contains one or more labels separated by `;` or `,`.

The default hierarchy path is:

```text
dataset/label_hierarchy.json
```

The Web of Science experiment uses:

```text
dataset/web_of_science/WOS46985.csv
dataset/web_of_science/WOS46985_hierarchy.json
```

To rebuild the local dataset from annotations:

```bash
cd dataset
python createDataset.py --hier label_hierarchy.json --ann ann.csv --out dataset.csv
```

## Environment

There is no pinned top-level environment file yet. The core RAE-HMC pipeline
uses the following main packages:

- Python 3.10 or newer
- PyTorch
- transformers
- numpy
- pandas
- tqdm
- faiss-cpu or faiss-gpu

Optional analysis and plotting scripts may also require:

- scipy
- matplotlib
- seaborn

Example setup:

```bash
pip install torch transformers numpy pandas tqdm faiss-cpu
pip install scipy matplotlib seaborn
```

Install the PyTorch build that matches your CUDA version if training on GPU.

## Usage

Run the default RAE-HMC pipeline:

```bash
python train_rae_hmc.py
```

Run RAE-HMC on WOS46985 with one seed:

```bash
python run_wos_multiseed.py --seed 41
```

Run a quick WOS46985 smoke experiment on a subset:

```bash
python run_wos_multiseed.py --quick --seed 41
```

Run WOS46985 across multiple seeds:

```bash
python run_wos_multiseed.py --seed-start 41 --seed-end 70
```

Run module ablations:

```bash
python run_ablation_multiseed.py --seed-start 41 --seed-end 70
```

Run contrastive-loss ablations:

```bash
python run_ablation_cl_multiseed.py --seed-start 41 --seed-end 70
```

Run baseline comparisons:

```bash
python run_baselines_multiseed.py --seed-start 41 --seed-end 70
```

Generate mean/std summaries and paired t-test tables:

```bash
python analyze_paired_test.py --input-csv outputs/baselines_multiseed/baselines_multiseed.csv
```

## Outputs

By default, experiment artifacts are written under `outputs/`, including:

- model checkpoints,
- memory stores,
- per-seed result files,
- CSV summaries,
- logs,
- plots.

The `outputs/` directory is intentionally ignored by Git because these files can
be large and are generated by running experiments.

## Baselines

This repository includes adapted baseline implementations for reproducibility:

- `baselines/BERT-FT`: BERT fine-tuning baseline for the RAE-HMC dataset.
- `baselines/HGCLR`: adapted from "Incorporating Hierarchy into Text Encoder:
  a Contrastive Learning Approach for Hierarchical Text Classification"
  (ACL 2022), MIT License.
- `baselines/HILL`: adapted from "HILL: Hierarchy-aware Information Lossless
  Contrastive Learning for Hierarchical Text Classification" (NAACL 2024),
  MIT License.

The original license files for HGCLR and HILL are preserved inside their
respective baseline directories.

Baseline checkpoints and generated outputs are ignored by Git:

```text
baselines/HGCLR/checkpoints/
baselines/HGCLR/outputs/
baselines/HILL/ckpt/
baselines/HILL/outputs/
```

## Notes for Reproducibility

- Random seeds can be controlled through the multi-seed runner arguments.
- WOS46985 uses `bert-base-uncased` by default.
- The local dataset pipeline uses `bert-base-chinese` by default.
- The memory module uses a FAISS inner-product backend.
- Large generated artifacts are excluded from version control and should be
  regenerated from scripts.
